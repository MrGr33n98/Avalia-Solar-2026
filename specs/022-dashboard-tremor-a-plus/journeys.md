# Jornadas e páginas
J1 Entrada: login → seleção empresa (0/1/N memberships) → resolução URL → shell → overview. Falhas: sessão expirada, pending, inválido, 403, troca rápida. US01–04,21–22,25.
J2 Performance: overview → período → drill-down analytics → buyer intent → ranking → export/ação. Preservar filtros, histórico e dado ausente. US05–06,14–16.
J3 Reputação: reviews → detalhe → resposta; coleta → formulário/link/QR/email → preview → confirmação; badges/widgets/embeds. US07–08.
J4 Presença: informações → categorias → produtos/serviços → projeto/mídias → materiais → formulário/CTA → publicação/moderação. US09–10.
J5 Comercial: lead → detalhe → mensagens → proposta → wizard → preview/PDF → envio explícito → acompanhamento; quote form e ICP. US11–13.
J6 Gestão: plano → billing → equipe/roles → settings → integrações → aprovações; confirmação e policies. US17–18,26,28.
J7 CRM interno: today → accounts/people/leads → pipeline/tasks/quotes → campanhas/audiences/templates → relatórios/settings → AI approvals. US19–20,28.
J8 Reviewer: perfil/journey → companies/favorites → reviews/proposals/publications/achievements/green-score/rewards → notificações/ajuda; role isolado. US21–22.
J9 Resiliência transversal: mobile, keyboard, back/forward, zoom, theme, offline, 429/5xx, reconexão. US23–24,27.

Cada jornada: capturar antes/depois com usuário sintético, rota, role/plano, eventos, duração, ações e erros; mapear caminho alternativo e retorno. Não enviar mensagem/proposta/campanha real no teste.
