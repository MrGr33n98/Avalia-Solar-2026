# Chat — documentação técnica

Documentação incremental da arquitetura MobiVolt AI, MobiVolt Success, Live Inbox e P2P Chat.

Domínios permanecem separados:

- MobiVolt AI: assistente consumidor.
- MobiVolt Success: assistente dentro do dashboard empresarial.
- Live Inbox: atendimento humano originado de uma conversa.
- P2P Chat: usuário e empresa.
- Lead Delivery: oportunidade entregue a integração externa.
- CRM: fora do core do Avalia Solar.
