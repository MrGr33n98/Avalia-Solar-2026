# E2E Security and Critical Paths

Matriz obrigatória para Playwright/RSpec: session A/B, token expirado/adulterado, realtime token inválido, isolamento de Inbox, lead explícito, recommendation payload, handoff humano, retorno ao bot, PWA offline, multi-widget e Success entitlements/Health/NBA.

Esta documentação define cenários; execução depende de Postgres, Redis, browser e provider mockado no CI.
