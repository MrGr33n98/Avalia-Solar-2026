# Source Provenance

`Chat::SourceProvenance` valida fontes persistidas em `ChatMessage.metadata`.

Tipos aceitos: `company_catalog`, `company_profile`, `company_review`, `knowledge_registry`, `company_health`, `next_best_action`, `platform_policy`.

Provenance serve auditoria, debug, QA e trust. Não precisa aparecer para usuário. Active Admin exibe prompt version e fontes por mensagem.
