## 📐 Technical Design

### Current Pain Points (Evidence)

**1. Companies Ranking Query (Slow)**
```sql
-- Current: 800ms (Sequential Scan)
SELECT companies.* 
FROM companies 
WHERE active = true AND category_id = 1 
ORDER BY rating DESC, reviews_count DESC 
LIMIT 20;
```

**2. Analytics Events Aggregation (Very Slow)**
```sql
-- Current: 1200ms (Sequential Scan)
SELECT event_type, COUNT(*), DATE(created_at) 
FROM analytics_events 
WHERE company_id = 123 
  AND created_at > NOW() - INTERVAL '30 days'
GROUP BY event_type, DATE(created_at);
```

**3. Reviews by Company (Slow)**
```sql
-- Current: 650ms (Sequential Scan)
SELECT reviews.* 
FROM reviews 
WHERE company_id = 456 AND approved = true 
ORDER BY created_at DESC 
LIMIT 10;
```

### Proposed Indexes

#### Migration 1: Companies Ranking Index
```ruby
# db/migrate/YYYYMMDDHHMMSS_add_companies_ranking_index.rb
class AddCompaniesRankingIndex < ActiveRecord::Migration[7.1]
  disable_ddl_transaction!
  
  def change
    add_index :companies, 
      [:active, :category_id, :rating, :reviews_count],
      name: 'idx_companies_ranking',
      algorithm: :concurrently
  end
end
```

**Rationale:**
- Covers WHERE + ORDER BY clauses
- Composite index eliminates sort operation
- DESC on rating/reviews_count for fast leaderboards

#### Migration 2: Analytics Time-Series Index
```ruby
# db/migrate/YYYYMMDDHHMMSS_add_analytics_company_time_index.rb
class AddAnalyticsCompanyTimeIndex < ActiveRecord::Migration[7.1]
  disable_ddl_transaction!
  
  def change
    add_index :analytics_events,
      [:company_id, :event_type, :created_at],
      name: 'idx_analytics_company_time',
      order: { created_at: :desc },
      algorithm: :concurrently
  end
end
```

**Rationale:**
- Optimizes time-series queries
- Supports both filtering and grouping
- DESC on created_at for recent-first access

#### Migration 3: Reviews Company Approved Index
```ruby
# db/migrate/YYYYMMDDHHMMSS_add_reviews_company_approved_index.rb
class AddReviewsCompanyApprovedIndex < ActiveRecord::Migration[7.1]
  disable_ddl_transaction!
  
  def change
    add_index :reviews,
      [:company_id, :approved, :created_at],
      name: 'idx_reviews_company_approved',
      order: { created_at: :desc },
      algorithm: :concurrently
  end
end
```

**Rationale:**
- Covers approved reviews filter
- Supports pagination (ORDER BY created_at)
- Used by company dashboard and public pages

## 🧪 Testing Strategy

### Performance Testing

```ruby
# spec/performance/database_indexes_spec.rb
RSpec.describe 'Database Indexes Performance', type: :performance do
  it 'companies ranking query <80ms' do
    benchmark = Benchmark.measure do
      Company.active.where(category_id: 1)
        .order(rating: :desc, reviews_count: :desc)
        .limit(20).to_a
    end
    expect(benchmark.real * 1000).to be < 80
  end
  
  it 'analytics aggregation <100ms' do
    benchmark = Benchmark.measure do
      AnalyticsEvent.where(company_id: 1)
        .where('created_at > ?', 30.days.ago)
        .group(:event_type, 'DATE(created_at)')
        .count
    end
    expect(benchmark.real * 1000).to be < 100
  end
  
  it 'reviews approved query <50ms' do
    benchmark = Benchmark.measure do
      Review.where(company_id: 1, approved: true)
        .order(created_at: :desc)
        .limit(10).to_a
    end
    expect(benchmark.real * 1000).to be < 50
  end
end
```
