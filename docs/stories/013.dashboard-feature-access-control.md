# Story 013: Dashboard Feature Access Control

Status: IMPLEMENTED_LOCAL

## Contexto

O dashboard já usa `planFeatures` em alguns módulos, mas ainda sem contrato uniforme.

## User Story

Como empresa cliente,
quero ver no dashboard apenas o que meu plano libera,
para entender claramente o que posso usar e o que exige upgrade.

## Escopo

- construir tabs a partir de `feature_access`
- introduzir wrapper `FeatureGuard`
- separar estados `enabled`, `locked`, `hidden`
- aplicar blur leve e overlay apenas em features apropriadas

## Critérios de aceite

- tabs bloqueadas aparecem apenas quando o estado for `locked`
- tabs `hidden` não aparecem na navegação
- tabs `enabled` mantêm experiência completa
- blur usa estilo leve e consistente
- nenhum dado sensível é entregue apenas para ser desfocado

## Dependências

- Story 011

## Verificação

- testes de frontend para tabs enabled/locked/hidden
- validação manual do dashboard
