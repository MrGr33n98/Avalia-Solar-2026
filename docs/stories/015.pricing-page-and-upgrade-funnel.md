# Story 015: Pricing Page and Upgrade Funnel

## Contexto

O app aponta para `/pricing`, mas a página não existe funcionalmente.

## User Story

Como potencial cliente,
quero comparar os planos e entender o valor de upgrade,
para decidir entre `Gratuito`, `Pro` e `Enterprise`.

## Escopo

- criar página `/pricing`
- manter aliases `/plans` e `/prices`
- expor comparação comercial coerente com o catálogo do V1
- alinhar a linguagem visual ao estilo Avalia Solar

## Critérios de aceite

- a página `/pricing` existe e substitui o placeholder atual
- `/plans` e `/prices` funcionam
- cards de plano apresentam diferenciação clara
- tabela de comparação reflete o recorte comercial do V1
- CTAs de upgrade apontam para jornadas válidas

## Dependências

- nenhuma para a versão estática
- Story 011 para a futura integração total com catálogo dinâmico

## Verificação

- build do frontend
- revisão visual responsiva
