# Story 012: ActiveAdmin Plan Console

Status: IMPLEMENTED_LOCAL

## Contexto

Hoje planos são operados com JSON cru no ActiveAdmin, o que é funcional, mas ruim para governança.

## User Story

Como administrador,
quero gerenciar planos por formulário estruturado,
para operar preços e funcionalidades sem editar JSON manualmente.

## Escopo

- substituir textarea principal por formulário orientado a catálogo
- agrupar features por contexto de negócio
- exibir preview do plano resultante
- exibir preview de `feature_access` na empresa

## Critérios de aceite

- admin consegue criar `Gratuito`, `Pro` e `Enterprise` sem editar JSON cru
- formulário possui grupos lógicos de features
- mudanças inválidas ou incoerentes são validadas
- empresa mostra plano atual e preview do acesso resolvido

## Dependências

- Story 011

## Verificação

- request specs/admin specs
- revisão manual do formulário no ActiveAdmin
