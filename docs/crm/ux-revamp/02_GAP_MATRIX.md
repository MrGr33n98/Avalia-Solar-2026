# 02 — Matriz de Gaps (Web x PWA)

## 1. Convenção da Matriz
- **GAP_ID:** Identificador sequencial.
- **Capacidade:** Domínio ou funcionalidade examinada.
- **Estado Comprovado:** `EXISTENTE_VERIFICADO`, `EXISTENTE_PARCIAL`, `GAP_CONFIRMADO`, `PROPOSTO`, `BLOQUEADO`.
- **Decisão:** `KEEP`, `REUSE_AS_IS`, `REFINE`, `REPLACE_IN_PLACE`, `DEFER`, `REJECT`.
