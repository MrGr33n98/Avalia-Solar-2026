# Tech Stack

## Frontend (AB0-1-front)
- **Framework:** Next.js (Pages / App Router)
- **Language:** TypeScript
- **Runtime:** Node.js
- **Styling:** Tailwind CSS, Tailwind Merge
- **Component Library:** Radix UI, shadcn/ui
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **State Management:** React Query / TanStack Query, Zustand, React Hook Form, Zod
- **Auth:** Better Auth
- **Testing:** Jest, Playwright
- **Others:** Driver.js, Embla Carousel, Dexie, html-to-image

## Backend (AB0-1-back)
- **Framework:** Ruby on Rails (API Mode + ActiveAdmin)
- **Language:** Ruby
- **Database:** PostgreSQL (with ActiveRecord)
- **Background Jobs:** Sidekiq + Redis
- **Storage:** ActiveStorage (Likely with local / S3 configurations)
- **Testing:** RSpec (configured in `.rspec`)
- **Code Quality:** RuboCop
- **Admin Panel:** ActiveAdmin
- **Containerization:** Docker / docker-compose
