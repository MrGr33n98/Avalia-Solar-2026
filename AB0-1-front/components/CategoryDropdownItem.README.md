# CategoryDropdownItem

## Mobile-First Interaction

- sem dependência exclusiva de hover
- accordion por tap/click
- alvo mínimo de toque em `48px`
- `aria-expanded` e `aria-controls` para leitores de tela

## Usage Notes

- itens com subcategorias abrem o submenu primeiro
- o link da categoria principal continua disponível dentro do submenu
- em desktop com ponteiro fino, hover funciona como preview curto
