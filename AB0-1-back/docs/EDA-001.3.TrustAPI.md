## Story
**As an** Energy Installer,
**I want** to access my trust metrics via a public API,
**so that** I can display my Avalia Solar reputation on my own website.

## Acceptance Criteria
1.  [ ] Migration adds `api_key:string:index` and `trust_score:decimal` to `companies`.
2.  [ ] `Api::V1::TrustController#profile` returns JSON with company trust metrics (verified, score, badges).
3.  [ ] `Api::V1::TrustController#widgets_config` returns rendering configuration for frontend components.
4.  [ ] `rack-cors` configured in `config/initializers/cors.rb` to allow cross-origin requests from company domains.
5.  [ ] `rack-attack` throttles `/api/v1/trust/` to 60 requests/minute per IP.
6.  [ ] Swagger documentation generated and accessible at `/api-docs`.
