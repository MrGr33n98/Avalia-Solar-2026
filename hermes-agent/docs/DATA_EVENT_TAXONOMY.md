# 📊 Taxonomia de Eventos de Dados e Conformidade LGPD: Hermes Agent

Este documento estabelece a especificação técnica dos schemas de eventos estruturados consumidos e disparados no ecossistema do **Avalia Solar & Mobilidade Elétrica**. Ele define os payloads mínimos, as origens, os destinos, os usos práticos na inteligência do **Hermes Agent** e avalia o impacto e riscos sob a ótica da **LGPD (Lei Geral de Proteção de Dados)**.

## 🛡️ Políticas de Proteção de Dados e Governança LGPD

1.  **Minimização de Dados**: O Hermes Agent apenas processa dados estritamente necessários para a execução dos fluxos. Campos opcionais e dados pessoais desnecessários à qualificação do integrador (como CPF de sócios, fotos pessoais) são ativamente rejeitados na validação primária.
2.  **Direito ao Esquecimento (Anonimização)**: Ao processar o evento `opt_out_requested`, o script do Hermes executa uma rotina de *Data Masking* (anonimização por hash criptográfico unidirecional). Os dados originais do lead são substituídos por strings genéricas (ex: `excluido_lgpd_hash@avaliasolar.com`), destruindo o vínculo pessoal sem corromper as métricas históricas de RevOps.
3.  **Logs de Consentimento e Transação**: Cada cadastro B2C ou B2B possui um campo de registro do consentimento (`consent_timestamp` e `consent_ip`). Esse dado é imutável e guardado com alta segurança para fins de auditoria em eventuais questionamentos jurídicos.
4.  **Isolamento Técnico de Erros**: Erros em payloads ou inconsistências de schema que contenham informações de identificação pessoal (PII) são redirecionados a uma área de sandbox técnica restrita e criptografada, impedindo o vazamento ou exibição nos canais abertos de logs e Slack.
