# 📊 Taxonomia de Eventos de Dados e Conformidade LGPD: Hermes Agent

Este documento estabelece a especificação técnica dos schemas de eventos estruturados consumidos e disparados no ecossistema do **Avalia Solar & Mobilidade Elétrica**, mapeados e atualizados diretamente com base na **estrutura real do banco de dados e endpoints do backend Rails** (`AB0-1-back`). 

Ele define os payloads mínimos em JSON (alinhados com as colunas exatas da base de dados PostgreSQL), as origens, os destinos, os usos práticos na inteligência do **Hermes Agent** e avalia o impacto e riscos sob a ótica da **LGPD (Lei Geral de Proteção de Dados)**.

## 🛡️ Políticas de Proteção de Dados e Governança LGPD

1.  **Minimização de Dados e Schemas Estritos**: Em total consonância com as colunas definidas no `schema.rb` do Rails, o Hermes Agent valida se campos confidenciais como `encrypted_password` ou `reset_password_token` nunca trafegam em payloads de eventos e são mantidos ocultos e isolados do barramento público de logs e de notificações no Slack.
2.  **Anonimização Automática por Hash Criptográfico**: Quando o evento `opt_out_requested` é ingerido, o Hermes Agent remove os dados pessoais das colunas `name`, `email`, `phone` e `address_full` da tabela `leads` no PostgreSQL, mantendo apenas a localidade (`city`, `state`) e métricas agregadas (`monthly_kwh`, `bill_value`) para fins estatísticos e de RevOps sem ferir o direito ao esquecimento.
3.  **Logs de Consentimento Imutáveis**: Alinhados com os campos `consent_at` e `consent_ip` da tabela `leads`, os dados de autorização de tratamento de dados são gravados no momento exato do cadastro de forma auditável e nunca podem ser sobrescritos por processos automáticos do Hermes.
4.  **Sandbox e Criptografia de Logs Técnicos**: Logs de erros operacionais contendo conteúdos completos de e-mails (`email_received`) ou mensagens do fórum (`forum_question_submitted`) são compactados e armazenados em tabelas de auditoria de acesso restrito (como `review_decision_logs` e `pending_changes`), impedindo vazamento de dados privados em ambientes de desenvolvimento ou relatórios compartilhados no Slack.
